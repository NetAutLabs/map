NetAut Labs Map (Minimal Scaffold)

This folder contains a minimal React + Vite SPA scaffold that demonstrates:

- Loading a local `labs.manifest.json`
- Rendering a map with interactive hotspots
- Opening labs in a new tab from the hotspot overlay

Quick start

```bash
cd site
npm install
npm run dev
```

Build for GitHub Pages

```bash
npm run build
# then publish `dist/` or configure GitHub Pages to publish from `site/` or `gh-pages` branch
```

Notes

- Replace the placeholder `labs.manifest.json` with your real lab entries.
